# ExamPYQs Product Rules

## Core principle

ExamPYQs helps students learn from Previous Year Questions.

## Never compromise

1. PYQ authenticity
2. Answer correctness
3. Explanation quality
4. Mobile usability
5. Performance
6. Data security

## Content distinction

Official PYQ != AI-generated practice.

Never represent generated questions as official questions.

## UX principle

Student should be able to:

Choose → Answer → Understand → Continue

with minimum friction.

## Product philosophy

Simple enough to maintain alone.

Professional enough to scale.

## Initial target

BPSC TRE Computer Science.

## Long-term target

Multi-exam platform.

## Current stack

Next.js
TypeScript
Tailwind
Supabase
PostgreSQL
Vercel
GitHub

## Deployment

Deploy early.

Do not wait until the entire product is complete.

## Architecture

Generic exam platform.

Never hard-code BPSC/TRE into core entities.

## Mobile

Mobile-first.

Desktop is progressive enhancement.

## Monetization

Future:

Ads for free users.

Plus for users who want an ad-free and enhanced experience.

Do not allow monetization to damage the learning experience.
